# 천명관상 V2 설계안 — 「개인형 생애 풀이」 전환

> 작성: 2026-11-06 · 상태: **2026-11-06 정식 배포 완료** (실사용 검수 통과 · 공유=전체 풀이 · 하단 버튼 3분할)

---

## 0. 왜 바꾸나 (한 문단 요약)

V1은 노예~황제 6등급을 AI가 판정했다. 등급의 기준이 "얼마나 좋은 사람인가" 하나뿐이었기 때문에, 정직하게 판정하면 누군가는 하층이 된다. 그래서 AI는 모두를 4등급(귀족)으로 모았고, 결과에 **차별성과 인사이트가 사라졌다.**
V2는 등급을 없애고, 그 사람의 **과거 · 현재 · 미래**를 시기별로 풀어 주는 개인형 서비스로 바꾼다.
핵심 원칙은 **"시기의 좋고 나쁨은 코드가 계산하고, AI는 그 계산을 사람의 말로 풀어 쓴다"** 이다.

## 1. 설계 원칙 (되돌리면 안 되는 결정)

| # | 원칙 | 이유 |
|---|---|---|
| 1 | **대운·세운·월운과 그 길흉 신호는 코드가 계산**한다. AI는 계산 결과를 근거로만 쓴다 | 사람마다 다른 결과(차별성) · 같은 입력이면 같은 결과(일관성) · 주의 시기를 빼먹지 않음(아부 방지) |
| 2 | **과거는 사건을 단정하지 않고 "시기의 성격"으로 쓴다** | AI는 실제 인생을 모른다. 단정했다가 틀리면 신뢰가 바로 무너진다 |
| 3 | **이직·이사·결혼은 "하라/마라"가 아니라 "언제가 유리한가"로 쓴다** | 실제 의사결정에 쓰일 수 있다. 결정은 본인 몫이다 |
| 4 | **수명·임종 시점·질병 진단은 쓰지 않는다.** 미래B는 「말년운 · 생애 정리」로 쓴다 | 불안을 유발한다. AI도 거부하거나 얼버무려 품질이 흔들린다 |
| 5 | **모든 시기에는 강점과 주의점이 함께 나온다** | 전부 좋다는 풀이는 인사이트가 없다. 주의점은 조언과 함께 쓴다 |
| 6 | **같은 입력은 저장된 결과를 다시 보여 준다** | 볼 때마다 결과가 바뀌면 개인형 서비스의 신뢰가 깨진다 |

## 3. 계산 엔진 (saju.js 재작성) — 코드가 맡는 부분

### 3-1. 원국 계산 정확도 보정 (V1 버그 수정)

| 항목 | V1 | V2 |
|---|---|---|
| 년주 | 양력 1/1에 바뀜 | **입춘 시각** 기준 |
| 월주 | 양력 1일이 경계 · 1월 천간 오류 | **12절(節) 시각** 기준 · 年干 기준 월간 정확 적용 |
| 일주 | 1900-01-01 甲戌 기준 (정상) · 자시 날짜 넘김 없음 | 유지 + 밤 11시~자정 출생은 다음 날 일주 (D5) |
| 시주 | 시진 선택 | 시진 선택 유지, 자시 2분할 (D1) |
| 오행 | 천간·지지만 셈 | **지장간 포함** 가중 계산 |

- **절기 시각 계산:** 외부 데이터 파일 없이 태양 황경 공식(Meeus 저정밀식, 오차 수 분 수준)으로 구한다.
- 구현 시 한국천문연구원(KASI) 24절기 표 일부를 테스트 정답으로 삼아 비교한다.

### 3-2. 새로 계산하는 것

| 계산 | 내용 | 결과에서 쓰이는 곳 |
|---|---|---|
| **신강/신약** | 일간을 돕는 기운(인성·비겁)과 빼는 기운(식상·재성·관성)의 가중 점수 | 전체 해석의 기준 |
| **희신/기신 (간이 용신)** | 억부법으로만 간단히 정함. 신강이면 설기·극하는 오행이 희신, 신약이면 생조하는 오행이 희신. ⚠️ 정통 용신론의 단순화라는 점을 명시한다 | 시기별 길흉 점수 |
| **대운** | 순행/역행(양남음녀 순행, 음남양녀 역행), 대운수(출생~다음/이전 절까지 일수 ÷ 3), 10개 대운 | 과거 · 미래B |
| **세운** | 해마다의 간지 (입춘 기준) | 현재 · 미래A |
| **월운** | 올해와 향후 3년의 월별 간지 (절 기준) | 좋은 달 / 조심할 달 |
| **십신** | 대운·세운·월운의 천간과 지지가 일간에게 어떤 관계인지 (비견·겁재·식신·상관·편재·정재·편관·정관·편인·정인) | 그 시기의 **주제** |
| **합·충·형** | 대운·세운 지지와 원국 지지(특히 일지·월지·년지)의 육합·삼합·충·형 | 그 시기의 **변동성** |
| **신살 (최소)** | 역마, 도화, 화개 3개만 | 이사 · 연애 · 학업과 내면 신호 |

### 3-3. 시기별 「신호 카드」 (코드가 만들어 AI에게 넘기는 것)

시기마다 아래와 같은 **사실 묶음**을 만든다. AI는 이것만 근거로 쓴다.

```json
{
  "period": "2027", "ganji": "丁未", "age": 47,
  "daeun": "庚戌 대운 (45~54세)",
  "sipsin": { "stem": "정재", "branch": "상관" },
  "score": 62,                       // 희신/기신 기반 0~100, 시기끼리 비교하는 상대 점수
  "themes": ["재물", "표현·이동"],    // 십신 → 주제 매핑
  "flags": ["일지 충 → 생활 기반 변동", "역마"],
  "good_months": [3, 4, 9],
  "caution_months": [6, 12]
}
```

**의사결정 신호 매핑 (전통 이론의 단순화):**

| 결정 | 코드가 보는 신호 |
|---|---|
| 이직·직업 변화 | 관성(정관·편관) 해, 월지 충, 식상의 관성 극 |
| 이사·이동 | 역마, 일지·년지 충, 인성 해(문서) |
| 결혼·연애 | 남성 = 재성 해, 여성 = 관성 해 · 도화 · 일지 육합 |
| 재물·투자 | 재성 해와 희신 여부, 비겁 과다(겁재 해)는 주의 |
| 학업·시험·계약 | 인성 해, 화개 |

- **점수 분포 검증:** 한 사람의 여러 시기 점수가 고르게 퍼지고, 사람끼리도 달라야 한다. 테스트로 확인한다 (§8).
- 특정 연도나 사람에게 점수가 몰리면 가중치를 조정한다.

## 4. 관상 — 유년운기로 시간축에 연결

얼굴 부위를 나이대에 대응시키는 전통 이론(유년운기)을 단순화해서 쓴다.

| 부위 | 대응 나이 (근사) | 연결 구간 |
|---|---|---|
| 이마 | 15~30세 | 과거 (초년) |
| 눈썹·눈 | 31~40세 | 과거/현재 (청년~중년 초) |
| 코·광대 | 41~50세 | 현재/미래 (중년) |
| 인중·입 | 51~60세 | 미래 (장년) |
| 턱 | 61세 이후 | 미래B (말년) |

- **AI 1차 호출 (관상 추출):** 사진에서 부위별로 `특징 한 줄 + 강/중/약` 만 구조화해서 받는다. 등급이나 길흉 판단은 받지 않는다.
- **코드:** 사용자 나이에 맞춰 각 부위를 과거·현재·미래 구간에 배정한 뒤 신호 카드에 붙인다.
- **비중:** 사진 관상은 한계가 크므로 **사주가 주(主), 관상은 보조 근거**로 둔다.
  - 예: "코의 기운이 단단해 40대 재물운을 받쳐 준다."
- V1의 인종 중립 원칙은 그대로 유지한다.

## 5. AI 역할과 호출 구조

### 5-1. 2단계 호출

| 단계 | 입력 | 출력 | 모델 (D4) | temperature |
|---|---|---|---|---|
| ① 관상 추출 | 사진 | 부위별 특징 · 강/중/약 (짧은 JSON) | Haiku 5.5 | 0.2 |
| ② 생애 풀이 작성 | 원국 요약 + 신호 카드 전부 + ① 결과 (텍스트만, 사진 재전송 안 함) | 4구간 풀이 JSON | Sonnet 5.5 | 0.4 |

- **나누는 이유:**
  - ①을 사진 해시로 저장해 두면, 같은 사진으로 다시 볼 때 관상 결과가 흔들리지 않는다.
  - ②는 사진 없이 텍스트만 보내므로 비용이 줄고 응답이 빨라진다.
- **max_tokens:** ②는 약 6,000 (V1은 3,000).
- **예상 응답 시간:** 40~90초. 로딩 문구를 단계별로 바꿔 보여 준다.

### 5-2. 풀이 작성 지침 (프롬프트의 고정 규칙)

1. 신호 카드에 없는 길흉을 지어내지 않는다.
2. `score`가 낮거나 `flags`가 있는 시기는 반드시 주의점을 쓴다.
3. 과거 구간은 "~했을 가능성이 크다", "~한 기운이 강했던 시기"처럼 쓰고, 구체적 사건을 단정하지 않는다.
4. 결정 가이드는 "하라/마라"가 아니라 "유리한 시기 · 신중할 시기"로 쓴다.
5. 수명, 사망 시점, 질병명은 쓰지 않는다. 건강은 "무리하지 않기" 같은 생활 습관 수준까지만 쓴다.
6. 아첨 금지. 강점과 주의점의 균형을 지킨다.
7. 출력 JSON은 **풀이를 먼저, 요약 키워드를 마지막**에 둔다. 결론부터 정하고 이유를 끼워 맞추는 것을 막기 위해서다 (V1 문제 ③).

### 5-3. 출력 JSON 구조

```json
{
  "past": {
    "periods": [
      { "range": "1~10세 · 丁卯 대운", "title": "…", "text": "…" }
    ],
    "summary": "지금까지의 삶을 관통하는 흐름 (2~3문장)"
  },
  "present": {
    "year": 2026,
    "overview": "올해의 전체 기운 (3~4문장)",
    "areas": { "work": "…", "money": "…", "relationship": "…", "health_habit": "…" },
    "good_months": "…", "caution_months": "…"
  },
  "future_near": {
    "years": [
      { "year": 2027, "text": "…", "keyword": "…" }
    ],
    "decisions": {
      "job":      "유리한 시기 / 신중할 시기 + 이유",
      "move":     "…",
      "marriage": "…",
      "money":    "…"
    }
  },
  "future_far": {
    "phases": [
      { "range": "50대", "text": "…" }, { "range": "60대 이후 (말년)", "text": "…" }
    ],
    "life_portrait": "이 사람이 생애를 어떤 모습으로 정리할지, 무엇을 이루는 사람인지 (4~6문장)"
  },
  "headline": "한 줄 요약 (공유 카드 제목용)"
}
```

## 6. 결과 화면

```
┌──────────────────────────────┐
│  丙午년 · 당신의 천명            │  ← headline (앱에 이름 입력은 없음)
│  [과거] [현재] [3년] [생애]      │  ← 목차 칩 (탭하면 해당 위치로 스크롤)
├──────────────────────────────┤
│ ☰ 사주 원국  (8글자 · 오행 바)   │
│ ▸ 대운표 펼치기  ──●── 지금     │  ← 10개 대운 가로 띠, 현재 위치 표시
├──────────────────────────────┤
│ ◐ 지나온 길 (과거)              │  대운별 카드 + 관상 근거 한 줄
│ ◉ 올해의 운 (현재)              │  분야별 4칸 + 좋은 달 / 조심할 달
│ ◑ 다가올 3년 (미래A)             │  연도별 카드 + 결정 가이드 4개
│ ○ 생애의 그림 (미래B)            │  장년 · 말년 + 생애 정리
├──────────────────────────────┤
│ ⓘ 본 풀이는 전통 명리·관상 이론에 근거한 참고용 해석입니다.
│   중요한 결정은 본인의 판단으로 하세요.
│ [📤 공유하기]  [🔄 새로 풀이]       │
└──────────────────────────────┘
```

- **공유:** 전체 본문은 너무 길기 때문에 요약본을 공유한다 (headline + 올해 요약 + 3년 키워드). 전체 복사 버튼은 따로 둔다.
- **저장:** 입력값과 사진 해시를 키로 localStorage에 저장한다. 홈에 「지난 풀이 보기」를 두고, 「기록 삭제」 버튼도 제공한다.
  - 저장되는 생년월일은 본인 기기에만 남는다.
- **보안:** V1은 AI 응답을 `innerHTML`로 넣는 부분이 있다(관상 목록). V2는 전부 `textContent`로 넣는다.

| D3 | 음력 생일 | **지원 안 함 — 양력만** | 음력 변환표 불필요 |

**알려진 한계:** 절기가 바뀌는 당일에 태어나고 시각이 경계 근처면, 시진 단위로는 월주(입춘이면 년주까지)가 틀릴 수 있다. 해당자가 극소수라 감수하고, 그런 날이면 결과 화면에 "절기 경계일 출생 — 월주가 다를 수 있음" 안내를 붙인다.

## 11. 구현 중 확인·보정한 것 (11/6)

- **절기 정확도:** 1900~2100년 절기 2,412개를 정밀 천문 라이브러리(astronomy-engine)와 비교했다. 최대 오차는 14분이다.
- **신강/신약 쏠림 보정:** 이론값 0.5로 자르면 300명 중 77%가 신약으로 판정됐다. 돕는 오행(비겁·인성)이 5개 중 2개뿐이기 때문이다. 경계를 모집단 중앙값(0.40)으로 옮겨 신강·약간 신강·약간 신약·신약이 각각 19·25·27·28%가 되게 했다.
- **점수 기준 변경:** 점수를 사람 간 비교가 아니라 **그 사람의 60갑자 전체 평균 대비 상대값(개인 표준화)** 으로 바꿨다. 보정 전에는 300명의 시기 중 46%가 '조정'으로 쏠렸고, 보정 후 대운 라벨은 상승 33 · 평탄 36 · 조정 32%다. 4년 흐름 패턴은 34종이고 가장 흔한 패턴도 11%다. 누구에게나 오르막과 내리막이 있다는 원칙이 이 숫자로 확인된다.
- **재현:** `node --test tests/*.test.js` (단위 테스트), `node tests/diversity.sim.js` (차별성 시뮬레이션)

## 부록: 이 설계의 한계 (사용자에게도 숨기지 않을 것)

- 희신/기신은 억부법만 쓴 **단순화**다. 정통 명리의 격국·조후까지는 반영하지 않는다.
- 사진 관상은 조명·각도·보정의 영향을 크게 받는다. 그래서 보조 근거로만 쓴다.
- "과거가 와닿는다"는 느낌의 상당 부분은 시기의 성격을 넓게 서술해서 생기는 효과다. 그래서 풀이는 **참고용 해석**으로 안내한다.
